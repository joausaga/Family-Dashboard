Family Dashboard

Una adaptación de Planify Dashboard para funcionar en Amazon Fire. Reúne eventos y rutinas de Google Calendar, tareas de Google Tasks, pronóstico de Open-Meteo y monitorización local de una TV Samsung.

Qué hace

Family Dashboard se ha adaptado y probado en una Amazon Fire HD 8 de 7.ª generación. Accede a Google Calendar y Google Tasks con permisos de solo lectura. No crea, modifica ni elimina eventos, calendarios, tareas o listas y no necesita Planify-APP ni Planify-Backend.

Los datos de Google se solicitan directamente a las API oficiales y se procesan en el dispositivo. La aplicación también puede consultar Open-Meteo para mostrar el tiempo de una ubicación elegida por la persona usuaria.

La TV se consulta en la red local mediante una IP configurada por la persona usuaria; su historial se guarda en el dispositivo. Se conserva la atribución y licencia MIT de la base de Planify, de eusonlito.
