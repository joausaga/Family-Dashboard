# Documentación de Family Dashboard

Adaptación de [Planify Dashboard](https://github.com/eusonlito/Planify-Dashboard) para Amazon Fire HD 8 (7.ª generación). Esta documentación describe la versión actual, no la preparación del hardware del proyecto original.

| Documento | Contenido |
|---|---|
| [SETUP.md](SETUP.md) | Compilación, instalación y configuración de la Fire |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Arquitectura, fuentes activas, caché y compatibilidad |
| [Google/OAuth](../GOOGLE_CLOUD_SETUP.md) | Calendar/Tasks, credenciales y límites de autorización |
| [Especificación vigente](../SPECS/current-version/SPEC.md) | Requisitos actuales |
| [Validación](../SPECS/current-version/TASKS.md) | Pruebas y pendientes |

`index.html`, `privacy.html` y `terms.html` forman el sitio público en GitHub Pages. `CNAME` mantiene su dominio configurado. Editar estos archivos localmente no publica el sitio ni modifica Google Cloud.
